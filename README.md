# ノート復習PWA

紙ノートの「教科＋ノート名＋番号＋題名」を復習単位として、復習予定・定着度・検索練習の形式を管理するiPhone向けPWAです。

## 使い方

1. Safariで公開URLを開きます。
2. 共有ボタンから「ホーム画面に追加」を選びます。
3. ホーム画面のアイコンから起動します。
4. 「登録」で教科、ノート名、番号、題名、初回日を登録します。
5. 「今日」で使える時間を選び、表示された検索練習を紙ノートを閉じて行います。
6. 復習後に0〜5の体感定着度を選ぶと、次回復習日が自動で更新されます。

## 通知（Web Push）

このアプリは**Web Push通知**で復習リマインダーを届けます。

- 朝・夜の2回、今日の復習がある場合のみ通知します。
- 復習予定が変わると、スケジュールが自動でサーバーに再同期されます。
- iPhone 16.4以降でホーム画面に追加したPWAで利用できます。

### セットアップ

1. [Render.com](https://render.com)で無料アカウントを作成します。
2. `server` フォルダをGitHubリポジトリにコミットし、Renderで「New Web Service」からデプロイします。
   - Build Command: `npm install`
   - Start Command: `node server.js`
3. 発行されたURL（例: `https://your-app.onrender.com`）をアプリの設定画面「通知サーバーURL」に入力します。
4. 設定タブで「通知を許可する」を押すと、Safariの許可ダイアログが表示されるので許可します。
5. 朝・夜の通知時刻を設定します（初期値: 07:00 / 20:00）。

### スリープ防止（UptimeRobot）

Renderの無料プランは15分間アクセスがないとスリープします。UptimeRobotで常時監視し、スリープさせないようにします。

1. [UptimeRobot.com](https://uptimerobot.com)で無料アカウントを作成します。
2. 「New Monitor」→「HTTP(s)」を選択。
3. URLに `https://your-app.onrender.com/health` を入力。
4. Intervalは無料プランの最速（5分）を選択。
5. 「Create Monitor」で完了。

5分ごとにヘルスチェックが入るため、Renderはスリープしません。無料枠（月750時間）でも常時起動（31日=744時間）は収まります。

### 注意点

- Renderの無料プランではサーバー再起動時に購読情報がメモリから消えますが、アプリを開くたびに自動再同期されるため問題ありません。
- 通知サーバーURLはIndexedDBに保存されます。
- 通知を止める場合は設定タブの「通知を停止する」を押します。

## 保存とバックアップ

学習データはIndexedDBに保存されます。アプリを閉じたりタスクキルしても通常は残りますが、Safariのサイトデータ削除、端末容量不足、URL変更では消えることがあります。

大事なデータは「JSONバックアップ」で定期的に保存してください。

バックアップJSONはアプリ更新後も読み込めるように、足りない項目を自動補完して復元します。古い形式のバックアップも、登録データが含まれていれば復元できます。`id` が無い古い形式のノートには、教科・ノート名・番号・題名から安定したIDを自動生成し、復習ログとの紐付けも維持します。

## ノート名の選択と絞り込み

- 登録タブでは、入力欄の下に「よく使うノート名」のチップが表示され、タップで選択できます。教科を入力すると、その教科で使われているノート名だけが候補に表示されます。
- 一覧タブでは、教科とノート名の2段階で絞り込めます。教科を選ぶと、ノート名の候補がその教科のものに絞られます。

## アップデートについて

アプリを更新した際、iPhoneのホームスクリーンアプリではService Workerのキャッシュが原因で古いバージョンが表示されることがあります。このアプリでは、更新があると「新しいバージョンがあります。再読み込みしてください」と表示されるので、その場合はアプリを一度閉じて開き直してください。

## 公開

GitHub Pagesなどの静的ホスティングに、このフォルダ内のファイルをそのまま配置できます。`server` フォルダは通知サーバー用です。

## サーバー構成

```
[iPhone PWA (GitHub Pages)]
    ↓ pushManager.subscribe() で購読登録
    ↓ 今日の復習スケジュールを送信
[Render.com 無料Node.jsサーバー]
    ↓ 朝・夜の指定時刻になったら web-push で送信
    ↑ UptimeRobot が5分間隔で /health を叩いてスリープ防止
[iPhoneに通知が届く]
