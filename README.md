# ノート復習PWA

紙ノートの「教科＋ノート名＋番号＋題名」を復習単位として、復習予定・定着度・検索練習の形式を管理するiPhone向けPWAです。

## 使い方

1. Safariで公開URLを開きます。
2. 共有ボタンから「ホーム画面に追加」を選びます。
3. ホーム画面のアイコンから起動します。
4. 「登録」で教科、ノート名、番号、題名、初回日を登録します。
5. 「今日」で使える時間を選び、表示された検索練習を紙ノートを閉じて行います。
6. 復習後に0〜5の体感定着度を選ぶと、次回復習日が自動で更新されます。

## 通知

このアプリはWeb Push通知ではなく、iPhoneカレンダー連携で通知します。

1. 「設定」から通知時刻を決めます。
2. 「カレンダー出力」を押して`.ics`ファイルを書き出します。
3. iPhoneで`.ics`を開き、カレンダーに追加します。
4. 通知音、バナー、ロック画面表示はiPhoneのカレンダー通知設定に従います。

前回出力した予定が残っている場合、再出力前にカレンダー側で削除してください。

## 保存とバックアップ

学習データはIndexedDBに保存されます。アプリを閉じたりタスクキルしても通常は残りますが、Safariのサイトデータ削除、端末容量不足、URL変更では消えることがあります。

大事なデータは「JSONバックアップ」で定期的に保存してください。

バックアップJSONはアプリ更新後も読み込めるように、足りない項目を自動補完して復元します。古い形式のバックアップも、登録データが含まれていれば復元できます。`id` が無い古い形式のノートには、教科・ノート名・番号・題名から安定したIDを自動生成し、復習ログとの紐付けも維持します。

## ノート名の選択と絞り込み

- 登録タブでは、入力欄の下に「よく使うノート名」のチップが表示され、タップで選択できます。教科を入力すると、その教科で使われているノート名だけが候補に表示されます。
- 一覧タブでは、教科とノート名の2段階で絞り込めます。教科を選ぶと、ノート名の候補がその教科のものに絞られます。

## アップデートについて

アプリを更新した際、iPhoneのホームスクリーンアプリではService Workerのキャッシュが原因で古いバージョンが表示されることがあります。このアプリでは、更新があると「新しいバージョンがあります。再読み込みしてください」と表示されるので、その場合はアプリを一度閉じて開き直してください。

## 公開

GitHub Pagesなどの静的ホスティングに、このフォルダ内のファイルをそのまま配置できます。
